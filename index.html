# Wi-Fi Dead-Zone Predictor ## Project Description An AI-based web application that predicts weak Wi-Fi signal areas using signal strength, router distance, and wall count. ## Features - Wi-Fi signal prediction - Dead-zone detection - Simple user-friendly interface - Signal status: Good, Weak, or Dead Zone ## Technologies Used - HTML - CSS - JavaScript ## Future Scope - Machine Learning prediction - Real-time Wi-Fi signal data - Floor-plan based Wi-Fi mapping
